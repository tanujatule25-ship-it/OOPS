# OOP with C++ — Unit 1: Basics of C++ & Classes

Practical code book programs for **Unit 1**, from the course
*Object-Oriented Programming with C++*.

All 8 programs are standalone, compile cleanly with `-std=c++17 -Wall`, and
produce the documented expected output.

## Index

| # | File | Concept |
|---|------|---------|
| 1 | `01_basic_data_types.cpp` | Basic data types (int, char, float) |
| 2 | `02_if_else.cpp` | Selection using if-else |
| 3 | `03_loop_and_array.cpp` | Loops and arrays |
| 4 | `04_functions.cpp` | Function prototypes and reuse |
| 5 | `05_class_and_object.cpp` | Class and object basics |
| 6 | `06_constructor_destructor.cpp` | Constructors and destructors |
| 7 | `07_static_member.cpp` | Static data members |
| 8 | `08_inline_friend_function.cpp` | Inline functions and friend functions |

## How to compile & run

**Linux / macOS**
```bash
g++ -std=c++17 01_basic_data_types.cpp -o program
./program
```

**Windows (MinGW)**
```bash
g++ -std=c++17 01_basic_data_types.cpp -o program.exe
program.exe
```

Replace the filename with any program from the index above.

## Topics covered

- Basic data types and I/O
- Selection statements (if-else)
- Loops and arrays
- Functions and prototypes
- Classes, objects, and the dot operator
- Constructors and destructors
- Static members
- Inline and friend functions
